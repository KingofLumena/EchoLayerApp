ARCHITECTURE
════════════════════════════════════════════════════════════════════════

Project Structure:
  echolayer/
  ├── config.py              # Configuration dataclasses
  ├── audio/
  │   └── processor.py       # Audio processing & latency measurement
  ├── layers/
  │   └── ultrasonic.py      # Ultrasonic signal generation
  ├── logging/
  │   └── logger.py          # CSV/JSON result logging
  └── gui/
      └── streamlit_app.py   # Streamlit web interface

Key Classes:
  - AppConfig: Configuration management
  - AudioProcessor: Audio I/O and latency measurement
  - UltrasonicLayer: Ultrasonic signal generation (18-22 kHz)
  - LatencyLogger: Result persistence (CSV/JSON)
  - EchoLayerGUI: User interface

Data Flow:
  1. Audio input → timestamp (ns)
  2. Process audio ± ultrasonic layer
  3. Audio output → timestamp (ns)
  4. Calculate latency = output_ts - input_ts
  5. Store measurement
  6. Update GUI statistics
  7. Save to logs on demand

USAGE
════════════════════════════════════════════════════════════════════════

Install Dependencies:
  pip install -r requirements.txt

Start Application:
  streamlit run app.py
  # or
  ./run.sh

Run Examples:
  python examples.py

Run Tests:
  PYTHONPATH=. python tests/test_integration.py

Access GUI:
  Open browser to http://localhost:8501

Conduct A/B Test:
  1. Click "Test Mode A (No Ultrasonic)"
  2. Click "Start Test" → Wait 10-30s → Click "Stop Test"
  3. Click "Save Results"
  4. Click "Test Mode B (With Ultrasonic)"
  5. Click "Start Test" → Wait 10-30s → Click "Stop Test"
  6. Click "Save Results"
  7. Compare results in logs/ directory
